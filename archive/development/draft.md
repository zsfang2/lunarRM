# 面向月球复杂地形的物理引导轻量化路径损耗图预测方法

> **英文题目（暂定）**：Terrain-Aware Lightweight Neural Network for Lunar Path Loss Map Prediction  
> **研究定位**：以局部数字高程模型（DEM）和发射机位置为输入，利用简化传播模型与轻量神经网络快速近似 Ray Tracing（RT）生成的 Path Loss Map。

## 1. 研究背景与目标

### 1.1 研究背景

月球表面分布着陨石坑、山脊、丘陵与粗糙地表，地形起伏会引起视距遮挡、绕射、反射及散射，使接收功率呈现复杂的空间分布。

高保真射线追踪（RT）可以模拟上述传播现象，但在大面积、多发射机位置或多频率场景下，其计算成本较高。现有直接从地形图预测 Radio Map 的深度网络虽然可加速推理，但往往缺乏显式传播机制建模，且较复杂的网络未必适合资源受限的部署环境。

### 1.2 研究目标

构建一个**轻量化、物理感知、具备跨地形泛化能力**的 Path Loss Map 预测模型，直接输出给定局部月球场景内的二维路径损耗分布，用于近似 RT 结果，而不必在每次推理时运行完整 RT。

给定：

- 局部月球数字高程图 $H\in\mathbb R^{M\times N}$；
- 发射机三维位置 $\mathbf p_{\mathrm{Tx}}$；
- 工作频率 $f$（以及相应的波长 $\lambda=c/f$）；
- 固定或明确给定的接收机高度、天线及地表电磁参数。

预测：

$$
\boxed{\hat L=f_\theta(H,\mathbf p_{\mathrm{Tx}},f)}
$$

其中 $\hat L\in\mathbb R^{M\times N}$ 为二维 **Path Loss Map**，单位为 dB。每个像素对应一个接收位置；若接收机高度或材料参数变化，应作为附加输入或单独控制实验变量。

**设计目标：**

1. **轻量化**：减少参数量和整体推理计算开销。
2. **物理感知**：显式利用距离、地形遮挡、菲涅尔区和绕射等信息。
3. **跨地形泛化**：尽量适应未见过的陨石坑、山脊及粗糙地形。
4. **可解释性**：区分解析传播基线与网络预测的修正量。

## 2. 方法总览

采用 **Physics-guided Lightweight Residual Network**：先构建简化物理传播基线，再利用轻量神经网络估计与高保真 RT 的偏差。

$$
\boxed{\hat L_{\mathrm{RT}}=L_{\mathrm{physics}}+\Delta L_\theta}
$$

- $L_{\mathrm{physics}}$：由解析近似得到的 Path Loss Map；
- $\Delta L_\theta$：地形感知网络预测的残差（dB）；
- $\hat L_{\mathrm{RT}}$：最终预测的 RT Path Loss Map。

```text
                  DEM + Tx位置 + 频率
                          │
             ┌────────────┴─────────────┐
             │                          │
       物理传播特征分支             地形几何编码分支
     距离 / FSPL / LoS /         相对高度 / 坡度 / 曲率 /
      Fresnel / Diffraction       Tx相对几何特征
             │                          │
             └────────────┬─────────────┘
                          │
               Lightweight Tiny UNet
                (预测 ΔLθ 残差图)
                          │
               L̂ = Lphysics + ΔLθ
                          │
                  Path Loss Map
```

该分解是一种**工程近似**：在 dB 域为传播基线添加修正项，并不意味着直射、反射和绕射等相干多径分量可以直接在 dB 域相加。

## 3. 模块 A：简化物理传播基线

### 3.1 三维距离与自由空间路径损耗

由 Tx 与每个接收网格点之间的**三维直线距离** $d(x,y)$ 计算：

$$
L_{\mathrm{FSPL}}(x,y)=20\log_{10}\left(\frac{4\pi d(x,y)}{\lambda}\right)
$$

注意，传播距离采用三维欧氏直线距离，而不是沿月球地表的测地距离。

### 3.2 视距及菲涅尔区特征

在 Tx-Rx 连线处提取 DEM 地形剖面：

$$
\mathcal P_{\mathrm{terrain}}=\{(s_i,h_i)\}_{i=1}^{K}
$$

根据地形剖面与 Tx-Rx 直射连线的相对高度，计算：

- **LoS Mask**：连线是否被地形遮挡；
- **Fresnel Clearance**：障碍物侵入第一菲涅尔区的程度；
- **最大绕射参数**：表示主导地形障碍的有效遮挡程度。

在简单剖面近似中，第一菲涅尔区半径：

$$
r_F=\sqrt{\frac{\lambda d_1d_2}{d_1+d_2}}
$$

刀刃绕射参数：

$$
\nu=h\sqrt{\frac{2(d_1+d_2)}{\lambda d_1d_2}}
$$

这里 $h$ 是障碍顶点相对直射路径的有符号高度，$d_1,d_2$ 是障碍与 Tx、Rx 的距离（采用与模型一致的几何近似）。

### 3.3 地形绕射基线

第一版可使用单刀刃绕射近似，之后扩展到圆滑障碍、多重障碍或 Bullington 模型。定义：

$$
L_{\mathrm{physics}}=L_{\mathrm{FSPL}}+L_{\mathrm{diff}}
$$

它是**有效路径损耗的简化基线**，用于降低网络学习难度，并非完整电磁场求解器。

第一版可优先考虑：

| 场景 | 传播近似 |
| --- | --- |
| 平坦、无遮挡 | FSPL；如有需要，加入双径近似 |
| 单个尖锐山脊 | 单刀刃绕射 |
| 圆滑山丘 | 圆滑障碍绕射 |
| 多个遮挡边缘 | 多重绕射 / Bullington |
| 复杂粗糙地形 | 物理基线 + 网络残差修正 |

**成本控制：**物理图生成是整个预测流水线的一部分。应比较仅用 FSPL、加入 LoS/Fresnel、加入绕射三种配置的精度—耗时权衡，避免复杂特征计算抵消轻量网络的速度优势。

## 4. 模块 B：局部地形几何编码

从 DEM 与 Tx 的相对几何关系中提取信息，而不是仅使用 Tx 的 One-hot 位置图。

| 特征 | 形式 | 物理含义 |
| --- | --- | --- |
| 相对高度图 | $H-H_{\mathrm{Tx}}$ | 地形与 Tx 的相对高度 |
| 坡度图 | $\|\nabla H\|$ | 局部地形起伏 |
| 曲率图 | $\kappa$ | 山脊、坑缘、圆滑地形形态 |
| 三维距离图 | $d(x,y)$ | Tx-Rx 距离关系 |
| LoS Map | $M_{\mathrm{LoS}}$ | 视距遮挡状态 |
| Fresnel Map | $M_{\mathrm{Fresnel}}$ | 菲涅尔区侵入程度 |
| 绕射损耗图 | $L_{\mathrm{diff}}$ | 近似地形遮挡损耗 |
| 物理基线图 | $L_{\mathrm{physics}}$ | 解析 Path Loss 估计 |

可选扩展：表面法向量、沿 Tx-Rx 剖面的方向曲率、不同尺度的地形粗糙度，以及与波长归一化的无量纲几何量。

**流形相关启发：**DEM 可以看作嵌入三维空间的二维曲面。坡度和曲率能够描述其微分几何性质，但并不要求电磁波沿地表传播。真实 RT 的直射、反射和绕射路径仍属于三维传播问题。

建议优先验证上述几何特征是否确实带来增益，再考虑更复杂的流形神经网络或 Laplace-Beltrami 算子。

## 5. 模块 C：轻量化残差预测网络

### 5.1 网络结构

第一版采用 **Tiny UNet + Depthwise Separable Convolution**：

- 小规模编码器—解码器，提取多尺度地形信息；
- 深度可分离卷积降低计算量；
- Skip Connection 保留传播边界和局部几何细节；
- 单通道输出路径损耗残差图。

可设置 **0.1M–0.5M 参数量**作为初始设计预算，实际规模由准确率与计算开销实验决定（不是已验证结果）。

### 5.2 输入与输出

一种候选输入组合：

$$
X=[H_{\mathrm{relative}},S,C,M_{\mathrm{LoS}},M_{\mathrm{Fresnel}},L_{\mathrm{physics}}]
$$

网络预测：

$$
\Delta L_\theta=f_\theta(X)
$$

最终结果：

$$
\boxed{\hat L_{\mathrm{RT}}=L_{\mathrm{physics}}+\Delta L_\theta}
$$

若要支持多频率，将频率或波长编码作为显式输入，并在不同频率下验证泛化能力。

## 6. 训练策略

### 6.1 监督数据

通过 **Sionna-RT** 在不同月球地形、Tx 位置及频率下生成参考 Path Loss Map：

$$
L_{\mathrm{GT}}=L_{\mathrm{Sionna\text{-}RT}}
$$

定义目标残差：

$$
\Delta L_{\mathrm{GT}}=L_{\mathrm{GT}}-L_{\mathrm{physics}}
$$

需统一 RT 输出定义、接收网格分辨率、接收高度、天线配置、材料参数及有效像素掩码。射线采样不足导致的空白区不能直接当作极大真实损耗。

### 6.2 损失函数

首先使用有效像素上的 MAE：

$$
\mathcal L_{\mathrm{PL}}=\frac{1}{|\Omega|}\sum_{(i,j)\in\Omega}|\hat L(i,j)-L_{\mathrm{GT}}(i,j)|
$$

其中 $\Omega$ 是有效监督像素集合。

为强调复杂地形遮挡区域，可增加 NLoS 加权损失：

$$
\boxed{\mathcal L=\mathcal L_{\mathrm{PL}}+\alpha\mathcal L_{\mathrm{NLoS}}}
$$

$\mathcal L_{\mathrm{NLoS}}$ 仅在有效的 NLoS 像素上计算。$\alpha$ 通过验证集确定，避免过度牺牲 LoS 区域精度。

## 7. 数据集与实验设计

### 7.1 地形类型

组合程序化合成地形与真实月球 DEM，覆盖：

1. 平坦月海；
2. 单山脊 / 单山丘；
3. 多重山脊；
4. 不同坑径、坑深和坑缘坡度的陨石坑；
5. 多尺度粗糙地表。

改变 Tx 位置、Tx/Rx 高度、频率及必要的地表材料参数，构造不同传播条件。

### 7.2 对比方法

| 方法 | 比较目的 |
| --- | --- |
| FSPL | 无地形信息的解析基线 |
| FSPL + Diffraction | 经典地形传播近似 |
| 纯数据驱动 Tiny UNet | 检查物理特征的贡献 |
| Physics-guided Tiny UNet（本文） | 完整方案 |
| 移除 LoS / Fresnel / Curvature | 物理与地形特征消融 |

如训练资源允许，可补充 RadioUNet、PMNet 或 RadioLunaDiff 作为更大模型的精度参考，但需要公平比较数据、频率设置和推理成本。

### 7.3 评价指标

- **预测精度**：Path Loss MAE / RMSE（dB）；
- **分区域误差**：LoS、NLoS 和深阴影区的误差；
- **泛化能力**：跨地形、跨 Tx 位置与跨频率测试；
- **模型复杂度**：参数量、FLOPs、峰值内存；
- **实际效率**：物理特征预处理 + 网络推理的总耗时，以及相对 RT 的加速比。

建议按**地形实例划分训练集与测试集**，避免同一幅 DEM 的高度相关区域同时进入训练和测试而高估泛化效果。

## 8. 预期创新点与待验证假设

### 创新点 1：Terrain-dependent Physical Feature Encoding

将 Tx 与地形之间的相对几何关系显式编码为 LoS、菲涅尔区、绕射、坡度和曲率等传播特征，而非仅输入原始 DEM。

### 创新点 2：Physics-guided Lightweight Residual Learning

将容易计算的传播规律交给解析模型，通过低参数量网络拟合解析基线与 RT 的系统误差，力争在精度和速度之间取得更好平衡。

### 创新点 3：Cross-terrain Generalization

探索物理量及尺度归一化几何特征是否能改善模型在未见过的月球地形、Tx 位置和频率下的泛化表现。

> 以上是**拟研究的贡献与假设**，需要通过消融实验和跨场景测试加以验证，不能预设一定优于纯数据驱动模型。

## 9. 关键挑战与注意事项

1. **解析基线的物理局限**：FSPL + 绕射不是完整 RT；反射与相干多径可能造成显著偏差。
2. **轻量化需要端到端计时**：DEM 剖面分析、LoS/Fresnel/绕射图生成的时间必须计入总开销。
3. **RT Ground Truth 的质量**：应明确射线数、传播机制及空间平均定义，区分真实低信号与仿真未命中。
4. **多尺度地形特征**：坡度和曲率计算依赖 DEM 分辨率，需考虑物理空间尺度和去噪。
5. **输入范围与泛化**：明确模型预测的是覆盖某个局部区域的一张 RM；当地形外部也影响传播时，输入 DEM 需包含相应上下文区域。

| 阶段 | 主要任务 | 预期产出 |

| P1 | 建立合成 DEM + Sionna-RT 数据集 | 统一的 RT Path Loss 监督数据 |
| P2 | 实现 FSPL / LoS / 单刀刃绕射 | 解析物理基线与各类特征图 |

| P5 | 扩展到真实月球 DEM、多频率 | 泛化评估与完整方法总结 |

## 11. 一句话总结

**本研究拟利用局部月球 DEM 和 Tx 位置提取地形感知传播特征，先以简化物理模型构建 Path Loss 基线，再以轻量 Tiny UNet 学习与高保真 RT 之间的残差，从而实现具备物理可解释性和跨地形泛化潜力的快速路径损耗图预测。**
