## 1. 项目背景与基础信息

### 1.1 研究问题

月球坑缘、山脊和粗糙地形会影响无线电传播。高保真射线追踪计算成本较高，本项目拟从局部数字高程图（DEM）、发射机位置和频率预测二维路径损耗图，近似当前数据集中已有的 RT 结果。

输入为一块地形及一个 Tx，输出为该频段的完整路径损耗图：

\[
\widehat L=f_\theta(H,\mathbf p_{\mathrm{Tx}},f),\qquad
\widehat L\in\mathbb R^{256\times256}.
\]

研究主线是物理残差学习：

\[
\widehat L=L_{\mathrm{FSPL}}+\Delta L_\theta.
\]

首先以三维距离计算 FSPL，再由轻量网络利用地形几何与遮挡特征预测修正量。是否优于直接预测必须由对照实验验证；dB 域残差是回归参数化，不代表相干多径分量可以直接在 dB 域相加。

## 2. 数据集介绍

### 2.1 数据规模与划分

每张图为 `256×256`，空间分辨率为 `1 m/px`，对应约 `256 m×256 m` 的地形 tile。

| 划分 | 地形数 | 每频段样本数 | 双频加载项数 | 本地可用情况 |
| --- | ---: | ---: | ---: | --- |
| train | 6,120 | 25,720 | 51,440 | 输入、标签、mask 均存在 |
| val | 680 | 2,330 | 4,660 | 输入、标签、mask 均存在 |
| test | 文档描述 1,200 | 文档描述 4,950 | 9,900 | 当前本地包无 test 数组，不能进行测试集评估 |

一个样本对应一个 `(terrain_id, tx_index)`；两个频段分别产生训练项，不是一次输出两张图。`single` 地形有一个 Tx，`multi` 地形有 51 个 Tx：训练集为 392 个 multi 与 5,728 个 single 地形；验证集为 33 个 multi 与 647 个 single 地形。

沿用官方固定 train/val，不对样本随机重新划分。`val_terrains.txt` 用于核验，不应再次用于扣除已经分好的验证集。

**泛化限制：**官方说明 8,000 个 tile 来自 500 个更大的 `1024×1024 m` 父地形。划分按 tile 进行，父地形可跨划分，且父地形映射未公开。因此只能称为“未见 tile 验证”，不能宣称完成父地形完全隔离测试。文档关于划分过程的文字存在不同层次描述，实际发布的索引与固定验证集优先于自行复现随机划分。

### 2.3 物理定义与仿真设置

| 属性 | 当前数据定义 |
| --- | --- |
| 高度 | 每个 tile 相对自身最低点的高度，单位 m |
| 路径损耗 | 正值约定：`PL = -10 log10(path_gain)`，单位 dB |
| 频率 | 415,000,000 Hz 与 5,775,000,000 Hz |
| Tx/Rx 高度 | 分别为局部地面以上 3 m / 1 m；Rx 随地形起伏 |
| 天线与功率 | Tx 为垂直极化各向同性设置，20 dBm |
| 引擎 | Sionna RT 1.1.0 |
| 传播机制 | LOS、镜面反射、漫反射、折射；未包含绕射 |
| 仿真规模 | 元数据记载最大交互深度 100、每 Tx 射线采样量 4×10⁹，并进行多 seed 处理 |

在该固定功率约定下，可通过 `RSS_dBm = 20 - PL_dB` 换算接收功率，但项目直接学习路径损耗。仿真环境依赖是数据生成信息，不代表预测训练环境需要安装 Sionna、Mitsuba 或 TensorFlow。

**绕射约束：**当前 GT 不含绕射。刀刃绕射只能作为探索性近似或遮挡特征对照，不作为默认物理真值，也不将其增益解释成恢复 GT 中的绕射机制。

### 2.4 有效 mask 与填充值

- `mask == 1` 表示有效监督像素；`mask == 0` 表示填充区域。
- 415 MHz 使用插值填充；5.775 GHz 包含固定 `145.0 dB` 填充。
- 数据说明报告 5.8 GHz 固定填充约占 11.4%，这是文档统计，实验另行统计本地各 split 的实际覆盖率。
- 不能通过 `PL == 145` 代替 mask：float16 量化后的真实值也可能等于 145。
- 有效性 mask 只用于损失和评价，不能作为预测输入；它不是 LoS mask。NLoS 像素也可能拥有有效 RT 标签。

### 2.5 当前 Kaggle 提交子集的性质

`manifest.json` 不是全数据文件清单，而是当前提交子集的说明：从公开 val 中选取 100 个样本、每地形一个 Tx、每图每频段 4,000 个像素，总计 800,000 行，公开/私有部分为 30/70 张图。

示例 CSV 列为 `ID,PL`，ID 规则为 `pl<band>_<sample_id>_<flat_pixel_index>`，像素索引按行优先展开。子集评分为 PL 列 RMSE，解答仅包含有效像素。

manifest 明确指出标签已公开，该榜单用于格式检查，不能作为独立泛化证据。主要研究结果必须来自完整固定 val；未来正式测试规则与提交接口应另行核验。README 所述完整地图提交与这里的子集 CSV 属于不同用途，不应混淆。

## 3. 官方加载接口与处理约定

### 3.1 参考接口

以下示例要求数据目录已加入 Python 模块搜索路径；项目实现可按绝对路径动态导入官方模块：

```python
from lunar_dataset import LunarRadioMapDataset

train = LunarRadioMapDataset(
    "/home/DataDisk/zsfang/lunarRM", split="train", band="both",
    normalize=True, augment=True, return_mask=True, return_name=True,
)
val = LunarRadioMapDataset(
    "/home/DataDisk/zsfang/lunarRM", split="val", band="both",
    normalize=True, augment=False, return_mask=True, return_name=True,
)
x, y, mask, name = train[0]
```

单频输入为 `(2,256,256)`，通道为高度图和 Tx one-hot；双频输入为 `(3,256,256)`，额外通道为频段标识（415 为 0，58 为 1）。标签与 mask 均为 `(1,256,256)` float32。双频样本按频段分块排列：先全部 415，再全部 58；短验证不能只截取开头若干 batch。

### 3.2 存储与数值约定

1. 保持原始文件只读，使用 `np.load(..., mmap_mode="r")`；float16 标签在读取后转 float32。
2. mask 通过 `np.unpackbits(packed).reshape(256,256)` 解包；不离线复制全部高度图和 Tx 图。
3. 官方归一化使用高度范围 `[0,496]` 和公共 PL 范围 `[20,228]`，并截断到 `[0,1]`。这两组值是训练集导出的归一化边界，不是每个样本的实际极值。
4. 官方加载器两个频段都使用公共 PL 范围，不能误用 metadata 中的逐频段范围进行反归一化。反变换为 `PL_dB = 208*y + 20`。
5. 新增特征的尺度采用固定物理常量或只由 train 估计的统计量，禁止使用 val/test 拟合归一化参数。

### 3.3 物理特征包装层

纯网络对照直接使用官方接口。物理分支应基于同一索引和 mask 语义，读取 `normalize=False, augment=False` 的原始米制 DEM 与 dB 标签；计算物理特征后，再执行统一归一化和同步增强，避免用归一化高度计算传播距离。

参考接口归一化会截断目标。正式评价使用原始 float32 dB GT，并检查有效标签是否超出 `[20,228]`；若存在，记录数量，不能悄悄用截断目标替代真实 GT。用于公平对照的各模型需采用同一训练目标处理方式。

增强仅用于训练：随机翻转与 90° 旋转。DEM、Tx、标签、有效 mask、物理基线及空间特征必须使用同一变换；若使用有方向的梯度或相对坐标通道，旋转时还需变换分量和符号，或在变换后的 DEM/Tx 上重新计算。

## 4. 预计方法与对照实验

### 4.1 物理与几何特征

以像素列为 x、行为 y，在数据栅格坐标系内统一计算，不额外对官方数据进行上下翻转。令地面高度为 H：

\[
z_T=H(r_T,c_T)+3,\quad z_R(r,c)=H(r,c)+1,
\]
\[
d=\sqrt{[(c-c_T)\Delta]^2+[(r-r_T)\Delta]^2+(z_R-z_T)^2},\quad\Delta=1\mathrm{m},
\]
\[
L_{\mathrm{FSPL}}=20\log_{10}(4\pi d f/c_0).
\]

实现应保证数值有限，并明确距离下限。Tx 同像素处三维距离为 2 m，不应错误置零。

候选特征依次加入：

| 特征 | 定义与使用要求 |
| --- | --- |
| 相对地面高度 | `H-H(r_T,c_T)`；与天线高度差分开定义 |
| Tx 相对坐标与距离 | 相对行列坐标、三维距离或对数距离 |
| 坡度 | 按 1 m 间距计算梯度模长，记录边界差分规则 |
| 曲率代理 | DEM 的离散 Laplacian；标注为曲率代理，不直接称为严格曲面曲率 |
| 几何 LoS | 在 Tx-Rx 水平投影路径采样 DEM，比较地形与三维直射线高度 |
| Fresnel 净空 | 根据频率与路径位置计算第一菲涅尔区半径，记录有符号净空定义 |
| 刀刃绕射近似 | 由主导障碍参数估计，只用于探索性实验 |

LoS/Fresnel 剖面采样需规定插值方式、步长、端点排除和零水平距离处理。初版采用双线性 DEM 插值、水平采样间隔不大于 1 m；再比较 0.5 m 与 2 m 的精度和耗时。几何 LoS 是从 DEM 估计的类别，不是官方逐路径 LOS 真值。

允许缓存确定性特征：地形特征按 terrain 复用，Tx 相关特征按 sample 复用，频率相关特征按 sample+band 区分。缓存记录数据标识、算法版本、采样参数、单位与 dtype；评测另行计入无缓存的特征生成成本。

### 4.2 实验矩阵

| 编号 | 方法 | 目的 | 优先级 |
| --- | --- | --- | --- |
| A0 | 三维 FSPL，无可训练参数 | 建立解析误差与耗时基准 | 必做 |
| N0 | 纯 Tiny U-Net：H、Tx、band 直接预测 PL | 轻量数据驱动对照 | 必做 |
| N1 | 已有普通 U-Net，约 1.96M 参数 | 容量参考，与旧代码衔接 | 资源允许时 |
| R0 | Tiny U-Net，输入 N0 通道加 FSPL，输出 FSPL 残差 | 检验基础物理残差方案 | 必做 |
| G0 | 与 R0 相同输入，直接预测 PL | 分离额外输入与残差参数化的影响 | 必做 |
| R1 | R0 加相对坐标、相对高度、坡度、曲率代理 | 检验几何编码增益 | 第二阶段 |
| R2 | R1 加 LoS 与 Fresnel 净空 | 检验遮挡特征与端到端成本 | 第二阶段 |
| D0 | FSPL＋单刀刃绕射，无网络 | 测量该近似与无绕射 GT 的偏差 | 探索性 |
| D1 | 以 D0 为基线的残差网络 | 检验绕射先验是否有帮助或有害 | 探索性 |

N0/R0/G0/R1/R2 采用相同 Tiny U-Net 主干、宽度和训练预算，记录因输入通道变化导致的参数差异。深度可分离卷积、GroupNorm、多尺度 skip connection 为初始结构选择；参数预算需通过实际统计验收。

残差以 dB 定义，可通过固定比例 `s=208 dB` 缩放网络输出：`PL_pred = FSPL + s*r_pred`。残差有正有负，输出头不加限制为正的激活，也不对残差套用绝对 PL 的 `[20,228]` 归一化。预测裁剪若采用，应作为单独后处理实验报告。

在完整方案上分别移除 LoS、Fresnel、曲率，并在相同特征下比较直接预测与残差预测。优先完成单因素对照，避免一次改变网络、损失、输入和训练轮数后归因。

### 4.3 损失与训练设置

保留 draft 的 masked MAE 作为第一组主实验，并增加 masked MSE 对照，以检验与 RMSE 评价目标的匹配性。不能预设 MAE 或 MSE 更好。

\[
\mathcal L_{\mathrm{MAE}}=\frac{\sum M|\widehat L-L|}{\sum M},\qquad
\mathcal L_{\mathrm{MSE}}=\frac{\sum M(\widehat L-L)^2}{\sum M}.
\]

双频训练默认按频段分别计算有效像素均值后等权组合；频段缺席的 batch 需有显式处理，优先采用均衡双频采样。若某项无有效像素，跳过该项并记录，避免除零。

NLoS 加权仅在第二阶段引入：`L = L_base + alpha*L_valid_NLoS`，候选 `alpha={0,0.1,0.5}`。区域为 `M_valid AND NOT M_geometric_LoS`，空区域不产生附加损失。所有对照同时报告 LoS 与 NLoS 误差。

| 设置 | 初始计划 |
| --- | --- |
| 输入/输出分辨率 | 256×256，不下采样监督标签 |
| 频段 | 双频条件模型为主，单频分别训练为后续对照 |
| 优化器 | AdamW，lr=3e-4，weight_decay=1e-4 |
| 调度 | 余弦学习率，按完整实验的总 epoch 配置 |
| Batch / workers | 16 / 4，依据设备显存和吞吐调整并记录 |
| 初步完整训练预算 | 20 epoch；若未收敛，再为比较组统一增加预算 |
| 种子 | 试验 2027；关键结果重复 2027、2028、2029 |
| 模型选择 | 固定完整 val 的双频 RMSE 等权平均最低 |
| 精度 | FP32 基准；GPU 可启用 AMP，损失归约使用 FP32 |

这些是拟采用设置，现有代码并未实现本文全部方案：当前脚本使用 masked MSE，后续需补充损失配置、物理模块、Tiny 网络与公平对照入口。短步数试跑仅检查功能，不与完整 epoch 结果混为一谈。正式训练前重新检查 GPU 可用性，不依据先前一次探测永久认定设备状态。

## 5. 评价协议与结果解释

### 5.1 主指标

对每个频段，在完整 val 上累计有效像素误差：

\[
\mathrm{RMSE}_b=\sqrt{\frac{\sum_{n,p}M_{n,p,b}(\widehat L_{n,p,b}-L_{n,p,b})^2}{\sum_{n,p}M_{n,p,b}}},
\quad S_{local}=\tfrac12(\mathrm{RMSE}_{415}+\mathrm{RMSE}_{58}).
\]

同时报告逐频段 MAE。累计量建议 float64；禁止直接平均 batch RMSE。验证须包含两个频段所有样本，不 shuffle、不增强、不 drop_last。短验证须预先固定每频段子集并注明样本数。

本地官方 README 描述最终排名还包含跨团队归一化，但未给出公式；`S_local` 是本项目模型选择指标，不能宣称等同最终官方名次得分。当前 Kaggle 子集的合并 PL 列 RMSE，也不等同上述两个 RMSE 的算术平均。

### 5.2 分组与泛化

- 报告有效几何 LoS/NLoS、single/multi、不同 mask 覆盖率组的误差及像素/样本数量。
- 可按训练集确定的坡度或粗糙度阈值分组；当前无官方“陨石坑/山脊”等类别标签，不凭样本外观赋予全数据类别。
- 每 tile 的 Tx 数不同，增加逐地形等权统计作为诊断；不得替代主像素汇总指标。
- val 属于调参与模型选择数据，结果标记为验证结果，不能描述为盲测。
- 跨 Tx 留出实验需在 multi 地形上另建协议，注明是否共享地形，不能与未见 tile 泛化混称。
- 跨频率实验可分别做 415→58、58→415，但应改用数值频率/波长编码，并隔离目标频段监督和拟合统计；两个离散频段只支持有限的迁移验证。

## 6. 执行阶段与验收产物

| 阶段 | 工作 | 验收产物 |
| --- | --- | --- |
| P0 数据核验 | 检查数组头、索引、split、数值、mask 覆盖率及双频接口 | 数据审计报告、文件版本/校验信息 |
| P1 特征正确性 | 实现 FSPL、几何特征、剖面 LoS/Fresnel；用平地和山脊等合成小案例核验 | 特征模块、单位测试、特征可视化与耗时记录 |
| P2 基础对照 | 实现 A0/N0/R0/G0；先接口检查，再按统一预算训练 | 可复现配置、完整 val 指标、权重与曲线 |
| P3 物理消融 | R1/R2、特征移除、MAE/MSE、NLoS 加权 | 消融表、分区域误差、端到端成本 |
| P4 稳健性 | 多 seed、频段/Tx 专项实验、可选较大模型对照 | 均值与标准差、失败案例与结论边界 |
| P5 后续扩展 | 正式 test 发布后适配；真实 DEM、新频率、含绕射 RT 需新增数据 | 独立协议；不作为当前完成条件 |

P0 至少核验：train/val terrain_id 无交集、hm_row 与 Tx 坐标合法、数组行数匹配、双频各首尾样本正确、mask 解包后为 0/1、有效标签有限，以及官方归一化往返的截断影响。

P1 至少核验：平坦无障碍的 LoS、已知山脊的遮挡、Tx 同像素距离、频率对 FSPL 的影响，以及翻转/旋转后标签和特征对齐。物理 mask 与有效 mask 独立保存。

每次正式运行使用独立输出目录，保存完整配置、代码与官方加载器版本、数据标识、seed、环境、逐 epoch 指标、最佳/最后 checkpoint。断点续训需保存优化器、调度器、AMP 与随机数/采样状态；不支持完全复现时明确说明。关键结果需能从 checkpoint 独立重算完整 val 指标。

最终对照表至少包含：方法、特征、损失、参数量、训练预算、两个频段的 MAE/RMSE、本地等权指标、LoS/NLoS 误差、网络与端到端延迟。可视化固定同一批样本，展示 DEM/Tx、GT、预测、有效 mask、误差与物理基线；不只展示表现最好的案例。
